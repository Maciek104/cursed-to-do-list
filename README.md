# 📝 Cursed To-Do List

Cursed To-Do List is a lightweight, browser-based task manager with a haunted-house aesthetic. Create a list of tasks, add due dates and descriptions, and keep track of completed work through an interface styled like a collection of eerie notes and old photographs.

Built with vanilla HTML, CSS, and JavaScript. No package installation or build step is required.

## 🛠️ Features

- **Task management** — create tasks with a required title and due date, add an optional description, and delete tasks when they are no longer needed.
- **Inline editing** — click a task's title, due date, or description to edit it directly.
- **Completion tracking** — mark tasks complete or active with a checkbox; completed tasks are visually distinguished.
- **Search** — filter tasks by title or description, with matching title text highlighted.
- **Sorting** — sort the task list by due date or alphabetically by title.
- **English and Polish interface** — switch languages using the flag buttons in the header.
- **Haunted visual theme** — dark backgrounds, vintage-inspired typography, and sepia-toned polaroid images create the app's spooky look.

> **Note:** Tasks are kept in memory only. They are cleared when the page is reloaded or closed.
